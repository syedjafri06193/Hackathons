## 🚀 Getting Started

### Prerequisites

```bash
python >= 3.10
# Google Cloud account with Agent Builder enabled
# $100 in Google Cloud credits (request at https://forms.gle/xfv9vQzfRfNCCVbG7)
```

### Installation

```bash
git clone https://github.com/your-org/your-repo.git
cd your-repo
pip install -r requirements.txt
```

### Configuration

```bash
# Set your Google Cloud project
gcloud config set project YOUR_PROJECT_ID

# Set environment variables
export GOOGLE_CLOUD_PROJECT=your-project-id
export MCP_SERVER_URL=your-mcp-server-url
```

### Running the Agent

```bash
python main.py
# or via Google Cloud Agent Builder console
```
