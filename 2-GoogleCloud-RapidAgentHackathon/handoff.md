# Handoff — MongoDB Natural Language Query Assistant
### Google Cloud Rapid Agent Hackathon

---

## Goal

Build a functional AI agent — powered by Gemini and Google Cloud Agent Builder — that integrates with the **MongoDB MCP server** to let developers query their MongoDB databases using plain English.

The agent should:
1. Read the user's MongoDB schema/collections
2. Accept natural language questions
3. Generate and execute the correct MongoDB query
4. Return formatted results with an explanation and optimization suggestions

**Track:** MongoDB  
**Deadline:** June 11, 2026 at 2:00 PM PT  
**Platform:** Web (minimum requirement)
