# Optimization Grand Challenge 2026 (OGC 2026)

**A global optimization competition by LG CNS and the Korean Institute of Industrial Engineers (KIIE)**

**Problem**: *The Grand Shipyard Puzzle: Pack the Block, Beat the Clock* — a large-scale combinatorial optimization challenge inspired by real-world shipyard logistics. Develop efficient algorithms for complex packing and scheduling problems under time constraints.

**Official Devpost**: [https://ogc2026.devpost.com/](https://ogc2026.devpost.com/)  
**Official Website**: [https://optichallenge.com/](https://optichallenge.com/) (or www.optichallenge.com)

## Key Details
- **Total Prize Pool**: KRW 200 million (approximately $130,000 USD)
- **Participants**: ~870 (from 48 countries, 577 teams as of recent data)
- **Format**: Two stages — Preliminary Round (online submissions) and Final Round (top teams)
- **Team Size**: 1–3 members
- **Eligibility**: Open to anyone worldwide (above legal age of majority), students, professionals, and enthusiasts. All countries/territories except standard exceptions. Duplicate registrations not permitted.
- **Submission Language/Tech**: Any methodology allowed (mathematical optimization, ML, heuristics, hybrids, etc.)
- **Open Source**: All finalist algorithm code and technical reports will be released as open source.

## How It Works
### Preliminary Round
- Submit algorithm code to the competition server.
- Automated evaluation and leaderboard.
- Top 30–40 teams advance (subject to change, based on scores and verification).

### Final Round
- Continued automated scoring.
- Submit Technical Report explaining the algorithm.
- Present approach and results to the organizing committee.
- Winners based on: automated scores, technical report, code review, and presentation.

**Evaluation Criteria**:
- Algorithm Performance (efficiency and accuracy)
- Technical Report (clarity and depth)
- Code Quality (readability, structure, reproducibility)

**Evaluation & Disclosure Policy**:
- Specific criteria at organizers' discretion.
- Individual results not disclosed; only final rankings.
- Participation implies consent to open-source finalist submissions.
- Awards revocable for misconduct (e.g., plagiarism).

## What to Build / Submit
